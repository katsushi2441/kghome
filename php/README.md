# Kurage 障害者グループホームナビ（kghome）

住所を入れると、近くの **障害者グループホーム（共同生活援助）・短期入所・施設入所支援・自立生活援助・
宿泊型自立訓練** を距離順に返します。住所・電話・利用できる時間・運営法人つき。
市区町村ごとの公表件数の推移と「前は載っていたのに、いまは載っていない事業所」、
さらに **運営法人ごとに、いくつ持っていて、いくつ消えたか** が出ます。

デモ: <https://kurage.exbridge.jp/kghome.php/>

## 置き方

PHPが動くレンタルサーバーに、この3つを置くだけです。データベースサーバーも常駐プロセスも要りません。

```
kghome.php
kghome_data/kghome.sqlite    ← 約21MB
kghome_data/.htaccess        ← Require all denied（SQLite の直読みを止める）
images/ogp/kghome.png        ← OGP画像（kghome_data 配下は拒否するので別の場所に置く）
```

必要なのは **PHP 8 と PDO SQLite** だけです（どちらも標準で入っています）。

heteml をお使いの場合は、置いた階層の `.htaccess` に次の1行が要ります。無いと PHP 5.6 で動いて
エラーになります。

```apache
AddHandler php-script .php
```

`kghome.php` の先頭にある `$SITE`（表示名）と `$OGP`（OGP画像のURL）を、ご自分のサイトに合わせて
書き換えてください。

## 画面

| URL | 内容 |
|---|---|
| `/` | 住所から探す（`?q=住所&kind=種別&km=範囲`） |
| `/corps` | 運営法人の一覧（事業所数の多い順・名前で絞り込み） |
| `/corp/{法人名}` | 法人ごとのページ（都道府県別の内訳・事業所一覧・消えた事業所） |
| `/pref/{都道府県}` | 市区町村別の一覧・推移・消えた事業所 |
| `/city/{都道府県}/{市区町村}` | 事業所一覧（政令市は `/{区}` まで） |
| `/office/{id}` | 事業所ごとのページ |
| `/gone` | 公表データから消えた事業所（全国・都道府県別・**法人別**） |
| `/api?q=住所` | JSON |
| `/data/offices.csv` `/data/gone.csv` | CSV |
| `/llms.txt` `/robots.txt` `/sitemap.xml` | AI検索・検索エンジン向け |

住所から緯度経度を出すのに国土地理院の住所検索だけを使います。事業所の座標は最初からデータに
入っているので、外部のジオコーディングサービスは不要です。判定は置いた場所で完結し、
外部のAIやAPIには何も送りません。

## データを新しくする

WAM NET のオープンデータは毎年 **3月末・9月末** に更新されます。同梱の2本を順に動かすと、
新しい `kghome.sqlite` ができます。

```bash
python3 scripts/fetch_sfk.py --all   # ZIP を落とす
python3 scripts/build_db.py          # → kghome_data/kghome.sqlite
```

配布 ZIP は「時点 × サービス種別」で分かれています。`_33` は共同生活援助であって
岡山県ではありません。CSV は **UTF-8 BOM付き**です（cp932 でも decode 自体は通ってしまい、
列名が化けたまま動きます）。

## 法人を法人番号で束ねていない理由

法人ごとのページは、**法人番号ではなく正規化した法人名**で束ねています。

公表データの法人番号には入力ゆれがあります。実測で、1社に13桁が6種類ついていたり、
13桁でない値が604件、空が1,513件ありました。番号で束ねると同じ法人がばらけて、
「この法人で何か所が消えたか」を数え落とします。

そのぶん、同じ名前の別法人（同名の社会福祉法人が複数の県に実在する場合など）が混ざります。
384名義・3,186事業所がこれに当たります。法人ページには見つかった法人番号を**全部**並べ、
都道府県別の内訳も出しているので、そこで見分けられます。

## この道具が言えること／言えないこと

| | |
|---|---|
| 言える | 公表データに載っている事業所と、その所在地・連絡先・運営法人 |
| 言える | ある時点の公表件数と、番号が公表データから消えたこと |
| 言える | 同じ法人が何か所・何都道府県に持っているか |
| **言えない** | **空き状況**（公表されていません） |
| **言えない** | **グループホームの定員**（共同生活援助は全件が空欄です） |
| **言えない** | **家賃・食費・光熱水費**（公表データにありません） |
| **言えない** | **支援の内容・職員の配置・夜間の体制**（公表データにありません） |
| **言えない** | **廃止したかどうか**（消えた理由は公表されていません） |

利用には市区町村が出す**受給者証**が要ります。高齢者の認知症グループホーム（介護保険）は
別の制度なので含みません。

## この分野の数字の読み方

**「施設から地域へ」は、住まいの数のうえでは、この向きで動いています。**

- 共同生活援助（グループホーム）の公表件数は 2021年11月末の 10,012 から 2026年3月末の 16,022 へ **1.60倍**
- 同じ期間に施設入所支援は 2,484 → 2,565 で **1.03倍**、ほとんど変わっていない

ただし公表件数の増加には**自治体の登録が進んだぶんが混ざる**ので、事業所がそのまま1.6倍に
なったとは書きません。

**増えた側だけを見ても分かりません。** 同じ期間に 1,618か所のグループホームが公表データから
消えています（2024年3月末より後だけで 1,150か所）。しかも全国に均等に散っているのではなく、
**同じ法人が同じ時点でまとめて消える**ことがあります。2024年9月末には473か所が一度に消え、
その202か所が1つの法人、52か所がもう1つの法人でした。

**消えた数だけを見てはいけません。** いま公表されている数と並べて読みます。消えた数が多くても
いまの数がそれ以上に多い法人は、法人の再編で事業所番号が付け替わった可能性が高く、住まいが
無くなったという話ではありません。逆に消えた数が多くていまの数が少ない法人は、実際に事業を
畳んだか、指定を取り消されたか、別の法人へ渡したかのどれかです。
**どちらなのかは公表データには書かれていません。**画面はこの書き分けをしています。
