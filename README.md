# kghome — Kurage 障害者グループホームナビ

住所を入れると、近くの**障害者グループホーム（共同生活援助）・短期入所・施設入所支援・
自立生活援助・宿泊型自立訓練**を距離順に返す。住所・電話・利用時間・運営法人つき。
市区町村ごとに公表件数の推移と「前は載っていたのに、いまは載っていない事業所」、
さらに**法人ごとに何か所持っていて何か所が消えたか**を出す。

- 公開: https://kurage.exbridge.jp/kghome.php/
- 構成: **PHP 1ファイル + SQLite**（常駐サーバー・ポート不要）

## データ

WAM NET（独立行政法人福祉医療機構）[障害福祉サービス等情報公表システムのオープンデータ](https://www.wam.go.jp/content/wamnet/pcpub/top/sfkopendata/)。
営利・非営利を問わず二次利用できると明記された公開データ。毎年3月末・9月末に更新。

2026年3月末時点の収録（合計 28,471事業所）。

| サービス | 事業所 | 定員の公表 |
|---|---|---|
| 共同生活援助（グループホーム） | 16,022 | **なし（全件が空欄）** |
| 短期入所 | 9,145 | あり（44,092人） |
| 施設入所支援 | 2,565 | あり（125,451人） |
| 自立生活援助 | 519 | なし |
| 宿泊型自立訓練 | 220 | あり（3,692人） |

**緯度経度は全件ある**ので、住所からの距離計算に外部のジオコーダは要らない
（入力住所の座標だけ国土地理院の住所検索を使う）。

配布 ZIP は「時点 × サービス種別」で分かれている。`_33` は共同生活援助であって
岡山県ではない。CSV は **UTF-8 BOM付き**（cp932 でも decode は通ってしまい、列名が化けたまま動く）。

**共同生活援助は定員が1件も入っていない。**16,022件すべて空欄であることを実測で確認した。
「定員0」ではなく「公表項目に入っていない」。だから画面に定員カードも定員列も出さない。

## 法人を法人番号で束ねない

法人番号には入力ゆれがある（実測）。

- ソーシャルインクルー株式会社に 13桁が **6種類**
- 株式会社恵に 1180001104517 / 180001104517 / 1180001104 の3種類
- 13桁でない値が 604件、空が 1,513件

番号で束ねると同じ法人がばらけて、「この法人で何か所が消えたか」を数え落とす。だから
**正規化した法人名（NFKC＋空白除去）を鍵にする**。そのぶん同名の別法人が混ざる
（384名義・3,186事業所）ので、法人ページに見つかった法人番号を全部並べ、都道府県別の内訳も出す。

## この分野の数字の読み方

**「施設から地域へ」は、住まいの数のうえでは、この向きで動いている。**

- 共同生活援助の公表件数 2021年11月末 10,012 → 2026年3月末 16,022（**1.60倍**）
- 同じ期間に施設入所支援 2,484 → 2,565（**1.03倍**・ほぼ横ばい）

ただし公表件数の増加には自治体の登録が進んだぶんが混ざるので、事業所がそのまま1.6倍になったとは
書かない。

**増えた側だけを見ても分からない。**同じ期間に 1,618か所のグループホームが公表データから消えた
（2024年3月末より後だけで 1,150か所）。しかも均等に散っているのではなく、**同じ法人が同じ時点で
まとめて消える**。2024年9月末には473か所が一度に消え、そのうち202か所が1法人、52か所が別の1法人だった。

**消えた数だけを見ない。いま公表されている数と並べる。**

- 消えた212 / いま339 → 法人の再編で番号が付け替わった色が濃い。住まいが無くなったとは限らない
- 消えた88 / いま19 → 実際に減っている

**どちらなのかは公表データには書かれていない。**画面もこの書き分けで止める。

## 作り直す

```bash
/usr/bin/python3 scripts/fetch_sfk.py --all   # ZIP（10時点 × 5種別）→ /mnt/data/kghome/raw
/usr/bin/python3 scripts/build_db.py          # → php/kghome_data/kghome.sqlite（21MB）
/usr/bin/python3 scripts/make_store_image.py  # OGP／商品画像 1200×630
/usr/bin/python3 scripts/deploy.py            # heteml へ（FTPは1接続）
```

画面の確認は `scripts/shot.py`。**headless chrome の `--screenshot` は `--window-size` を
切り取り幅としてしか扱わない**ので、390pxで撮ったつもりでも広い版面の左390pxが写るだけになる。
`shot.py` は CDP で本当に端末幅にしてから撮り、`scrollWidth` を読んではみ出しを数字で確かめる
（320/360/390/430px × 8ページ）。

```bash
cd php && php -S 127.0.0.1:18387 -t .
/usr/bin/python3 scripts/shot.py http://127.0.0.1:18387/kghome.php outputs/shots
```

## 同じ型の製品

WAM NET の29サービス種別はすべて同じ29列のスキーマなので、`KINDS` を差し替えるだけで別の
困りごとに答える製品になる。

- [kshuro](../kshuro) — 就労継続支援A型・B型（30,867事業所）
- [khoudei](../khoudei) — 放課後等デイサービス・児童発達支援（56,258事業所）
