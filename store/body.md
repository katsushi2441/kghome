### 先に、このデータの限界を書きます

**空き状況は分かりません。** 公表データに入っていないからです。入居できるかどうかは事業所に聞くしかありません。

**グループホームの定員も分かりません。** 共同生活援助は16,022件すべて定員が空欄でした。「定員0」ではなく、公表項目に入っていません。定員が出るのは短期入所・施設入所支援・宿泊型自立訓練だけです。

**家賃・食費・光熱水費も分かりません。** 実際に毎月いくら払うかは事業所ごとに違い、公表データにありません。

**消えた事業所が廃止したかどうかも分かりません。** 公表データから消えた、という事実だけを書いています。法人の再編で事業所番号が付け替わった場合も「消えた」に数えられます。

**公表件数が増えた＝事業所が増えた、でもありません。** 自治体の登録が進んだぶんが混ざります。

分からないものを分かったように書かない。それがこの道具の設計です。

---

### 何ができるか

**住所を入れると、近くの住まいが近い順に出ます。**

| 収録しているサービス | 事業所数 | 定員の公表 |
|---|---|---|
| 共同生活援助（グループホーム） | 16,022 | **なし** |
| 短期入所 | 9,145 | あり（44,092人） |
| 施設入所支援 | 2,565 | あり（125,451人） |
| 自立生活援助 | 519 | なし |
| 宿泊型自立訓練 | 220 | あり（3,692人） |

2026年3月末時点、合計28,471事業所。**緯度経度が全件そろっている**ので、住所からの距離がそのまま出ます。利用できる時間（平日／土／日／祝）・定休日・電話・事業所のサイト・運営法人も表示します。

あわせて、次のページが最初から入っています。

- **法人ページ** … どの法人が、どこに、いくつ持っていて、いくつ消えたか
- **都道府県ページ（47）** … 市区町村別の一覧表と、半年ごとの公表件数の推移
- **市区町村ページ（1,400超）** … 事業所一覧・推移・消えた事業所。政令市と東京23区は**区ごとのページ**も
- **事業所ページ（28,471）** … 連絡先・運営法人・近くの住まい
- **CSV と JSON API** … `/data/offices.csv`、`/api?q=住所`
- **sitemap.xml・llms.txt** … 検索エンジンとAI検索の両方に向けた索引

### 「施設から地域へ」は、数字に出ています

| 時点 | グループホーム | 施設入所支援 |
|---|---|---|
| 2021年11月末 | 10,012 | 2,484 |
| 2026年3月末 | 16,022（**1.60倍**） | 2,565（**1.03倍**） |

グループホームだけが増え、入所施設はほとんど変わっていません。住まいの数のうえでは、方針はこの向きで動いています。

### ただし、増えた側だけを見ても分かりません

同じ期間に**1,618か所のグループホームが公表データから消えて**います（2024年3月末より後だけで1,150か所）。

しかも、全国に均等に散っているのではありません。

| 最後に公表された時点 | 消えたグループホーム |
|---|---|
| 2024年9月末 | **473か所** |
| 2025年3月末 | 296か所 |
| 2025年9月末 | 206か所 |

**2024年9月末の473か所のうち、202か所が1つの法人、52か所がもう1つの法人でした。**

### だから、法人を主語にした画面があります

グループホームは全国16,022か所を**10,744法人**が運営しています。1法人あたり平均1.49か所で、ほとんどは1〜2か所の小さな法人です。ところが最も多い法人は**1社で339か所を40都道府県**に持っています。

法人ページでは、その法人について次の4つを並べて出します。

- いま公表されているグループホームの数
- 住まい全体の数と、種別の内訳
- 何都道府県に広がっているか
- 公表データから消えた数（2024年3月末より後の内訳つき）

**消えた数だけを見てはいけません。**いまの数と並べて読みます。消えた数が多くてもいまの数がそれ以上に多い法人は、法人の再編で事業所番号が付け替わった可能性が高く、住まいが無くなったという話ではありません。逆に消えた数が多くていまの数が少ない法人は、実際に事業を畳んだか、指定を取り消されたか、別の法人へ渡したかのどれかです。**どちらなのかは公表データには書かれていません。**画面はこの書き分けをしたうえで、両方の数を並べます。

### 法人番号で束ねていない理由

法人ごとのページは、**法人番号ではなく正規化した法人名**で束ねています。

公表データの法人番号には入力ゆれがあります。実測で、1社に13桁が6種類ついていたり、13桁でない値が604件、空が1,513件ありました。番号で束ねると同じ法人がばらけて、「この法人で何か所が消えたか」を数え落とします。

そのぶん、同じ名前の別法人が混ざります（384名義・3,186事業所）。法人ページには見つかった法人番号を**全部**並べ、都道府県別の内訳も出しているので、そこで見分けられます。**この判断は画面にもREADMEにも書いてあります。**

### なぜ要るのか

障害のある家族の住まいを探すとき、多くの家庭は相談支援専門員に聞くか、事業所のサイトを1件ずつ開いています。国は全国のデータをオープンデータとして出していますが、**サービス種別ごとにZIPで分かれたCSV**で、住所から引ける形にはなっていません。ましてや「この法人は他にどこに持っているか」「いくつ消えたか」は、10時点ぶんのCSVを突き合わせないと出てきません。

この道具は、そのCSVを住所と法人から引ける形に変えただけです。ただし、変えるときに「分からないもの」を混ぜないようにしています。

### 置き方（3分）

1. `kghome.php` と `kghome_data/` を置く
2. その階層の `.htaccess` に `AddHandler php-script .php` を書く（共有サーバーの既定がPHP5.6のことがあるため）
3. `https://あなたのドメイン/kghome.php/` を開く

**データベースサーバーも常駐プロセスもポートも要りません。** 必要なのはPHP 8とPDO SQLiteだけです（どちらも標準で入っています）。書き込み権限も不要です。

住所から緯度経度を出すのに国土地理院の住所検索を使いますが、つながらない環境では「取得できませんでした」と表示して止まります（「事業所がありません」とは書きません）。事業所の座標は最初からデータに入っているので、外部のジオコーディングサービスは要りません。**判定は置いた場所で完結し、外部のAIやAPIには何も送りません。**

### 更新のしかた（年2回）

WAM NETのオープンデータは毎年3月末・9月末に更新されます。同梱のPythonを2本動かせば、新しいデータベースができます。

```
python3 scripts/fetch_sfk.py --all
python3 scripts/build_db.py
```

### こんな方に

- **相談支援事業所・相談支援専門員** … 近隣の選択肢を距離つきで一覧にして渡せます。「この法人は他にどこに持っているか」もその場で出ます
- **家族会・親の会・支援団体** … 「親亡き後」の相談で、通える範囲の住まいを地図ではなく一覧で示せます
- **議員事務所・行政** … 自分の自治体でグループホームが何か所増え、何か所消えたのかを事業所名と法人名つきで示せます。CSVはそのまま委員会の資料に使えます
- **福祉系のメディア** … 法人ごとの増減をたどれます。自分の名前で公開できます（MITライセンス）
- **自治体のDX担当** … 国のオープンデータを住民が引ける形にする例として、そのまま流用できます
